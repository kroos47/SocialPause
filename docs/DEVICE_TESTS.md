# Galaxy S24 Ultra acceptance — 0.6.0

Build success does not certify Samsung behavior. Use the real phone with Accessibility, notifications and precise alarms enabled. Keep the existing signing key and install over the old app; do not uninstall merely to fix a signature mismatch.

1. **Upgrade:** existing history, app selection, Sleep Time, lunch and running state remain. Updating from 0.3/0.4 must preserve existing partial usage and cooldown deadlines. Upgrading from 0.2 resets old timers once to 7/10 minutes. Reopen repeatedly: current usage must not reset again.
2. **Independent limits:** use Instagram for seven minutes. It redirects Home and starts a 60-minute cooldown immediately; X and Reddit remain available. Use X for ten minutes; its unlock time is ten minutes later than Instagram's. With Shared timer off, exceed twenty total minutes across apps without a shared cutoff.
3. **Pause:** leave a partially used app, switch to an unselected app, or lock the screen. Usage freezes. Return and resume the exact remainder. Cooldowns continue while locked. Opening the notification drawer or Quick Settings over a selected app must keep charging that app; close the drawer and verify no jump or icon switch. Opening the Settings app, Home or Recents pauses usage. Leave the drawer open through allowance exhaustion and verify Home redirection.
4. **Reset:** Instagram's cooldown expires even if no other app was used. Only Instagram resets. Keep another app focused during that transition and check its usage continues.
5. **Home and blocking:** inspect mixed and all-cooling states. Every card has its own timer; the mint summary shows availability/resting state. Reopening a cooling app returns Home. The overlay shows the correct 7/10-minute limit and unlock time and dismisses on lock.
6. **Notifications:** selected app focus shows its timer; Home/unselected focus shows the expanded overview. Check mixed/all-cooling rows, progress bars, and each separate timer. During active usage, check the requested app-icon/countdown status chip; otherwise verify the SocialPause icon without a timer chip. Opening the drawer must retain the active app notification. Try Clear all, individual swipe, lock/unlock, permission denial and regrant. A swipe should restore an ordinary notification while active, without repeated alerts or live promotion. Stop and Sleep Time must prevent restoration. Samsung may control or suppress promotion; record what actually occurs.
7. **Sleep:** verify both overnight and same-day windows. Notifications disappear at the start and return after the end. Timers keep enforcing limits.
8. **Lunch:** scheduled or manual start grants a full unrestricted hour, then blocks all for one hour and restores allowances. Early Stop lunch starts a full blocked hour. Manual lunch can replace any cooldown, once per local day. Start it before auto lunch and check auto is skipped; after auto lunch, one extra manual start is available. Check disabled Start after use, Stop/Start, process recreation, reboot and midnight persistence. Confirm a pending edit cannot cut short an overnight lunch/cooldown.
9. **Insights Today:** only per-app used time, no chart/large total card. Lunch/Stop usage is excluded. Usage sums across independent cycles.
10. **Insights Week:** colored segments sum to each day's total. Tap each bar or empty day; total and By App change to that date while the chart remains weekly. Tap the same day again or elsewhere outside day targets to restore totals; selecting another day switches directly. Scrolling must keep selection. Future days are disabled. Rotate while selected, switch Today/Week, and test a new week boundary.
11. **Appearance/accessibility:** dark/light mode, large text, gesture/button navigation, landscape, TalkBack day selection, and notification expansion. Test Samsung split-screen/pop-up focus: only the focused unlocked app should consume usage.
12. **Lifecycle:** closing or swiping the dashboard from Recents does not stop monitoring. Process recreation keeps timers and history. Reboot may reset timers but preserves settings/history. Stop permits free use; Start refreshes allowances. Disable SocialPause Accessibility during usage, cooldown and lunch: tracking stops, all notifications/overlays disappear, no alarm recreates them, and reopening shows Start disabled. Re-enable access: monitoring stays stopped until Start. Ordinary disconnection with permission still enabled must not reset timers.

Use fake-clock scenarios for exact boundaries; normal phone acceptance should also include a real cooldown and screen-off/idle interval. Do not shorten production constants to make a test pass. Collect only SocialPause-related logs; do not share private app data.

## Status-bar countdown regression

Use X briefly: drawer and Home counters must continue working. Verify the chip shows decreasing `MM:SS` with the X glyph when Samsung promotes it. Switch apps, open/close the drawer, then Home: the focused app stays stable through the drawer and idle has only the SocialPause icon. Check Instagram starts at 07:00 and others at 10:00.

The user confirmed the S24 Ultra displays the live countdown after enabling **Phone Settings → Developer options → Live notifications for all apps**. Keep that setting enabled; it affects compatible apps generally. If the number disappears, check that switch and the app-specific Live notifications controls in Samsung's notification/Now bar settings. Menu availability varies by firmware. Android's promotion flag alone does not prove a Samsung live pill is visible.

- **Shared timer:** while stopped, toggle it on. Settings offers 00:05, 00:10, …, 01:00 (default 00:20). Save persists; Cancel/outside dismissal leaves the old value. Both controls explain why edits are unavailable while running.
- **Shared accounting:** use Instagram 7 minutes, X 10, Reddit 3 with 20-minute shared allowance. Each app limit starts its own cooldown; Reddit's third minute starts a 60-minute group block. All apps reset when it finishes. Separately, let an app's cooldown finish while shared time remains: only that app refills, shared time does not. Test 5-minute shared exhaustion before an app's own limit.

The chip uses SocialPause's icon when shared time limits usage; idle and group cooldown show ordinary notifications with correct labels/rows. Drawer focus and Sleep Time behavior remain.

Verify effective-date copy. Open clock picker, change draft, tap outside or Back: nothing changes. Save while boundary passes uses the save-time decision.

Selection persists with a 10-minute allowance. Cancel discards; clearing all selections reports an error in the same dialog without saving.
- **Upgrade:** install 0.5 over 0.4 using the same signing key while an app is partly used, cooling down, or in lunch. Preserve history/settings/timers and initialize only new shared/manual fields. Keep the temporary status-bar diagnostic absent.
